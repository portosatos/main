# Экспорт сессий агента

Сюда **пользователь** кладёт экспорт сессий ИИ-агента, которым делался проект (требование заказчика,
`CLAUDE.md` §4). Агент эти файлы не создаёт и не правит.

Что положить:
- экспорт сессии планирования (в ней составлен и утверждён `docs/plan.md`, там же дословный запрос на план);
- экспорт каждой сессии шага (`один шаг — одна сессия`, см. `docs/plan.md`).

Рекомендуемые имена файлов: `NN-step-X.Y-<кратко>.<расширение>`, например `01-step-0.1-repo-and-logs.md`,
а для планирования — `00-planning.md`. Перед коммитом проверьте, что в экспорте нет секретов
(токенов, паролей, содержимого `.env`).

Агент напоминает об экспорте в конце проекта (шаг 13.2).
