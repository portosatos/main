# Экспорт сессий агента

Экспорт сессий ИИ-агентов, которыми делался проект (требование заказчика, `CLAUDE.md` §4). Положил автор проекта
в конце работы.

## Что в архиве `sessions.zip`

Файлы — исходные записи сессий в формате JSONL, как их сохраняют инструменты.

- `claude-code/` — 34 сессии Claude Code (десктоп-приложение Claude, модель Claude Opus 5.5) из папки проекта:
  по сессии на шаг плана от 0.1 до 13.2 (`один шаг — одна сессия`, см. `docs/plan.md`). Файлы пронумерованы
  по порядку и подписаны временем первой записи (UTC). Шаги 8.3–12.1 сделаны с другого аккаунта Claude
  (тот же инструмент и модель).
- `codex/` — 2 сессии Codex (GPT-6): начало шага 7.1, когда закончился лимит Claude (ADR-042). Шаг 7.1
  продолжил и закрыл Claude Code.

## Что изменено и чего нет

- **Личные email автора** в записях заменены на `<author-email>` (71 вхождение). Больше ничего не менялось.
  Перед публикацией записи проверены на токены, ключи и пароли — их нет (тестовые пароли демо-пользователя
  из `.env.example` не секретны).
- **Не приложены** по решению автора, потому что в них личные данные:
  - сессия, в которой составлялось ТЗ (`CLAUDE.md`, `docs/SPEC.md`): итог и все решения — в этих файлах
    и в `docs/PROMPTS.md`;
  - сессия, в которой составлялся `docs/plan.md`: итог — сам план и раздел «Принятые решения» в нём;
  - отдельная сессия Claude, которая работала консультантом автора: читала отчёты агентов, предлагала ответы
    и вручную проверяла работу на живом стеке. Её проверки записаны в `docs/WORKLOG.md` (например, повторная
    ручная проверка шагов 8.3–12.1) и в ответах автора в `docs/PROMPTS.md`.
- Не приложена служебная сессия «удаление папки тз» (до старта проекта, к коду не относится).
