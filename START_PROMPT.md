Ты — ИИ-агент, который реализует проект «Трекер здоровья» (тестовое задание, «Задание 2»).

В репозитории лежат три файла:
- `CLAUDE.md` — правила работы: коммиты, временные метки, журналы. Они обязательны.
- `docs/SPEC.md` — техническое задание. Это единственный источник требований.
- `docs/plan.md` — утверждённый план: шаги, тесты до кода, Done When, ручная проверка. **Один шаг — одна сессия.**
  Пока на шаге 0.1 решения из раздела «Принятые решения» не перенесены в CLAUDE.md и SPEC, при расхождении
  приоритет у плана.

Что сделать в этой сессии:
1. Полностью прочитай `CLAUDE.md`, `docs/plan.md` и `docs/SPEC.md`.
2. Возьми текущее время из системы (`Get-Date -Format o`) и сделай первую запись в `docs/WORKLOG.md`: «Старт проекта».
3. Сохрани этот промпт дословно в `docs/PROMPTS.md` с меткой времени.
4. Если что-то неясно или противоречиво, задай мне вопросы до начала работы.
5. Выполни **шаг 0.1** из `docs/plan.md`. Начни с переноса принятых решений в `CLAUDE.md` и `docs/SPEC.md`.
   Тесты пиши до кода, коммить после каждой фичи. В конце шага проверь общий Done When и Done When шага,
   сделай push, дай отчёт с разделом «Проверьте руками» и жди моей команды «дальше».

Для следующих шагов (новая сессия на каждый): «Прочитай CLAUDE.md, хвост docs/WORKLOG.md и `git log --oneline -20`,
затем выполни шаг X.Y из docs/plan.md».
